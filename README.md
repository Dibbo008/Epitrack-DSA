# EpiTrack – Enterprise Pandemic & Hospital Management System 

EpiTrack is a high-performance pandemic management system designed to streamline hospital resource allocation, patient tracking, and vaccination analytics during health crises. Built using C++ with Object-Oriented Programming and advanced Data Structures & Algorithms (DSA), EpiTrack leverages Binary Search Trees (BST), MaxHeap, QuickSort, and Binary Search to execute medical logistics operations with high computational efficiency and minimal memory footprint.

## Features 

• Dynamic Hospital & Vaccine Center Registration — efficient resource allocation using dynamic pointer arrays
• Patient Management via BST — O(log n) patient record insertion, discharge, and searching
• Vaccination Analytics Dashboard — QuickSort algorithm to rank centers by total vaccination counts
• Fast Center Search — Binary Search implementation for instant center record retrieval
• Emergency Triage Queue — MaxHeap structure to prioritize patients by severity
• Audit Trail Logging — Stack-based system for tracking center activities and audit history
